## Task 4: version-matcher + suppression logic (TDD)

**Files:** `src/lib/dep-vulns/version-matcher.ts`, `tests/dep-vulns-version-matcher.test.ts`

- [ ] **Step 1: tests for `matchVersion`.**
  - Version inside vulnerable range → returns the matched range
  - Version outside all ranges → null
  - Version exactly at the patched_in boundary → null (patched)
  - **Multi-range advisory** (vulnerable in `>=1.0.0 <1.4.2` AND `>=2.0.0 <2.1.3`):
    - `1.0.5` → vulnerable (range 1)
    - `1.4.2` → null (patched in range 1)
    - `2.0.5` → **vulnerable** (range 2; range-aware patch evaluation prevents false negative)
    - `2.1.3` → null (patched in range 2)
  - Version in `non_vulnerable_versions` → null (suppressed)
  - Invalid version → null + telemetry-eligible warning
  - Prerelease like `1.0.0-beta.1` against `<1.4.2` → null (prereleases excluded by default)
  - v-prefix `v1.2.3` → normalized to `1.2.3`
- [ ] **Step 2: implementation.** Per spec v3 §6.
- [ ] Commit: `feat(arc-186): range-aware version matcher with multi-range patch evaluation`
